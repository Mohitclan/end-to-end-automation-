Snippet test page

Local test page for the cookie banner check (task P2.02). It runs posthog-consent.html from this folder exactly as the website will. Serve it with:

python3 -m http.server 8790 --bind 127.0.0.1 -d site-snippet

then open http://127.0.0.1:8790/test-page.html in a private window. Events go to the real PostHog project, marked with this localhost URL.
